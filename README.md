# VO2max Lab — Documentation

Public documentation site for [VO2max Lab](https://github.com/fscanu/vo2max-lab) Android app: privacy policy and landing page.

Source repo (private): `fscanu/vo2max-lab` (not public for IP protection).

## Live site

- Landing: https://fscanu.github.io/vo2max-lab-docs/
- Privacy Policy (EN): https://fscanu.github.io/vo2max-lab-docs/privacy-policy/
- Privacy Policy (IT): https://fscanu.github.io/vo2max-lab-docs/privacy-policy-it/

## Stack

- Jekyll (theme: minima)
- GitHub Pages (auto-publish from `main` `/` root)
- `robots.txt` blocks indexing pre-launch (remove `Disallow: /` when v1.0.0 ships on Play Store)

## Update workflow

Privacy Policy changes are written first in the private app repo (`vo2max-lab/docs/`) and mirrored here for publishing. Keep both in sync.
